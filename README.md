# One-in-All Trade System

This Streamlit application implements the "One-in-All Trade System" strategy, providing entry, stop-loss, target, and exit signals based on advanced technical analysis.

## Features

- Mother Candle Breakout
- VWAP Reversal Logic
- EQ + FUT Buy/Sell Conditions
- Backtesting with performance metrics
- Interactive equity curve visualization
